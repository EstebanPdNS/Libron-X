# Changelog

## v0.5 — 2026-10-21

### Changelog

- Open independent Bible commentary panes and switch resources in place.
- Follow the active Bible or choose a specific source, with pause and workspace restoration.
- Read whole-chapter notes with explicit verse ranges, linked articles and original illustrations.
- Follow actual verse scrolling across chapter changes and retain the next-note behavior of study Bible companions.
- Present illustrated commentary with native text/image split views and image enlargement.
- Preserve blue underlined references, compact pinned note cards and Liquid Glass controls.
- Normalize original note markers and assemble overlapping chapter fragments in source order.
- Delete automatic Bible groups by language persistently and restore them when needed.
- Resolve ranges ending in explicitly named numbered books, including Samuel and Corinthians.
- Add an optional native public-domain commentary pack: Barnes, Clarke, Jamieson–Fausset–Brown, Matthew Henry Concise and Wesley.
- Choose and cycle commentaries that cover the current Bible reference.
- Cycle matching commentaries with keyboard arrows.
- Adapt commentary controls to narrow panes while retaining overflow actions.
- Open commentaries from the Library as synchronized commentary readers.
- Download encrypted resource collections by pasting an LX2 code.
- Resolve public Icedrive file links without an account and refresh expiring download addresses.
- Support direct HTTPS downloads and public Filen file links.
- Show per-resource progress, outcomes and download errors.
- Cancel downloads and continue later by repeating the same code.
- Retry transient network failures automatically.
- Verify encrypted objects, decoded files and completed resource packages.
- Skip verified resources already installed.
- Reuse verified cached objects across collections and when repairing resources.
- Back up replaced packages and roll back failed installations.
- Install collection dependencies and supplied reading fonts.
- Refresh the Library automatically after collection installation.
- Prepare compressed, deduplicated and encrypted collection catalogs and file objects.
- Link personal notes to their selected source text without modifying the resource.
- Open pinned personal-note previews and jump directly to editing.
- Validate note anchors against the source text before displaying links.
- Rename notes and delete selected notes with confirmation.
- Create a note directly with Command-N and focus its editor.
- Sort Library columns by their displayed values with stable ordering.
- Use searchable native choosers for Bibles, dictionaries and commentaries.
- Filter resource choosers by title, author, language or filename.
- Open chooser selections with double-click, Enter or the Open button.
- Switch Bible groups or open a selected version in a new reading pane.
- Look up the current word in the explicitly selected dictionary.
- Show or hide Strong numbers where a linked annotated edition is available.
- Restore the Strong-number setting with saved workspaces.
- Resolve original edition aliases after library package organization.
- Organize native resource names, metadata, Strong companions and commentary indexes with publishing tools.
- Open a new reading pane with Command-T.
- Close the active reading pane with Command-W while keeping the desktop open.
- Focus in-resource search with Command-F.
