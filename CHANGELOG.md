# Changelog

## v0.5.1 — 2026-10-21

- Add encrypted collection downloads with integrity checks and reusable cache.
- Add linked personal notes and note management.
- Improve library sorting and resource selection.
- Fix commentary coverage, Bible navigation and synchronized reading.

## v0.5 — 2026-10-19

- Add independent commentaries that follow the active Bible.
- Synchronize chapter notes, articles and illustrations.
- Improve reference ranges and Bible groups.
- Add an optional public-domain commentary pack.

## v0.4 — 2026-10-18

- Add indexed library search with scopes, fields, ranges and advanced queries.
- Add collections, priorities and resource associations.
- Add bibliographies, citations and duplicate review.
- Improve native imports, note cards and Bible switching.

## v0.3 — 2026-10-17

- Add twelve offline dictionaries and indexed lookup.
- Improve Bible navigation, linked readers and workspace restoration.
- Preserve supported formatting, images, tables and links.
- Add notes, highlights and refined pane layouts.

## v0.2 — 2026-10-17

- Import e-Sword and EPUB resources as native .libron packages.
- Add library filters, Bible groups and dictionary lookup.
- Add pane layouts, reading controls and help in ten languages.
- Add GitHub updates and reorganized settings.

## v0.1 — 2026-10-16

- Initial public beta.

## Bug reports
