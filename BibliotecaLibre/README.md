# Libron-X Swift package

The current macOS application is the `LibronXRebuild` product (`MacRebuild` target). `LibronX` (`BibliotecaMac`) is an earlier prototype retained for comparison and its existing tests.

Start at the [project README](../README.md). See [development](../docs/development.md), [architecture](../docs/architecture.md) and the [complete source map](../docs/source-map.md).

```sh
scripts/test.sh
scripts/build-rebuild-app.sh
```

The application is created at `dist/Libron-X.app`. Original books, licenses and executables are not distributed.
