# Beta compatibility

v0.1 is the first public Mac beta. It is intended for testing, with backups of personal study data.

| Area | Current scope | Limit |
| --- | --- | --- |
| macOS | SwiftUI/AppKit workspace; macOS 14 deployment target | Release binary is Apple Silicon; older OS versions and Intel execution are unverified |
| Resources | Metadata and supported LSF/LIX, LBXLLS and OEB reading paths | Recognition does not guarantee complete rendering or all embedded objects |
| Navigation | Article history, Bible references, linked readers and parallel groups | Edition mapping and unusual references remain partial |
| Search and topics | Bounded local searches, supported query grammar and original topic indexes | Full original indexed, morphological and specialized search is incomplete |
| Documents | Notes, verse lists, favorites and owned workspace snapshots | Original document and add-in compatibility is partial |
| Output | Selected clipboard, print and text/web/native export paths | Layout fidelity and destination-app behavior require further comparison |
| Languages | English, Mandarin, Hindi, Spanish, Arabic, French, Bengali, Portuguese, Indonesian and Urdu choices | Some messages and document names remain Spanish; linguistic and accessibility acceptance is incomplete |
| Distribution | Ad-hoc signed app ZIP | No Developer ID signature or Apple notarization |

The portable Core and CLI are separate from the Mac app. Historical Windows research does not establish a Windows desktop release. No Linux, Windows or mobile application binary is included in v0.1.

Full original Libronix workflow parity remains unverified. Test counts, parsed articles and screenshots describe specific checks; none measures whole-application completeness. Legacy scripts and proprietary runtime modules are not executed by this implementation. Original books, fonts, licenses and program files must not be added to the public repository.
